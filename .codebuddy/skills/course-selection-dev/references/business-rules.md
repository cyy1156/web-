# 选课业务规则

规则来源：上海理工大学《全日制本科生选课办法》及教务处、各学院历年选课通知（公开页面）。本文件是校验逻辑的唯一口径，改规则必须同步改这里。

## 一、三轮选课

| 轮次 | 时间 | 业务含义 | 系统行为 |
|---|---|---|---|
| 第一轮（海选） | 每学期第 12 周 | 学生按指导性修读意见选课，充分尊重意愿 | 先到先得、额满为止；允许退课 |
| 第二轮（补选） | 每学期第 15 周 | 依第一轮结果对教学班取消或合并，释放资源 | 只允许选有余量的班；允许退课 |
| 第三轮（退改选） | 开课学期第 3 周 | 试听 2 周后自主调整教学班 | 允许退课与改选；结束后名单锁定 |

- 只有 `selection_round.status = 'OPEN'` 且当前时间落在 `[start_time, end_time]` 内才允许写操作，否则返回 `40001`。
- 第三轮结束后 `semester.locked = 1`，学生端全部按钮置灰，接口返回 `40010`。
- 名单锁定后 `enrollment` 只读，主讲教师按该名单评定成绩。

## 二、学分约束

| 项 | 规则 |
|---|---|
| 下限 | 15.0 学分（该学期未完成学分已不足 15.0 者除外） |
| 上限 | 一般 30.0 学分，且含重修学分 |
| 浮动 | 不超过培养计划设定学期学分的 ±30% |

实现：`credit_rule` 表按 `major_id + term_no` 配置 `plan_credits / min_credits / max_credits`，取其与 30.0 的较小值作为实际上限。校验时用"已选学分 + 本次课程学分 > 上限"判定。

提示文案必须给出具体数字，例如"超出学期学分上限，已选 28.5/30.0 学分，本课程 4.0 学分"。

## 三、校验顺序（固定，不可调整）

```
1. 轮次窗口     最便宜，先挡掉窗口外请求
2. 重复选课     单表索引查询
3. 容量        原子扣减，尽早失败
4. 学分        聚合查询
5. 时间冲突    位图运算
6. 先修        多表关联
7. 跨年级      单字段比较
```

顺序理由：把最贵的学生成绩/培养计划关联查询放在最不可能执行到的位置，热点路径上只保留 2 次索引查询 + 1 次 UPDATE。

## 四、错误码

| code | 含义 | 前端提示示例 |
|---|---|---|
| 40001 | 不在选课时间窗口 | 当前不在选课时间内，第一轮将于 10-26 09:00 开放 |
| 40002 | 教学班容量已满 | 该教学班名额已满 |
| 40003 | 时间冲突 | 与《大学物理》周三 3-4 节冲突 |
| 40004 | 先修课未通过 | 需先修《高等数学A(1)》且成绩合格 |
| 40005 | 学分超限 | 超出学期学分上限（已选 28.5 / 30.0） |
| 40006 | 已选过 / 重复提交 | 你已选过该课程 |
| 40007 | 跨年级越级 | 低年级不可选修高年级课程 |
| 40008 | 该课程不可退 | 必修课不可退选 |
| 40009 | 请求过于频繁 | 操作过快，请稍后再试 |
| 40010 | 名单已锁定 | 选课名单已锁定，无法变更 |
| 40100 | 未登录 | 请先登录 |
| 40300 | 无权限 | 无权访问该资源 |

## 五、边界场景

| 场景 | 期望行为 |
|---|---|
| 退课后重新选同一门课 | 允许；`status_flag` 生成列为 NULL 不参与唯一索引 |
| 同一课程选两个不同教学班 | 拒绝 40006（`uk_stu_course` 拦截） |
| 一门课可选多个教学班时退掉其中一个 | 允许 |
| 教学班被停开（`status='CANCELLED'`） | 已选学生保留记录但课表不展示，管理员需手工调整 |
| 学生已修课程成绩 59 分 | 视为未通过，重修学分计入上限 |
| 跨年级补修低年级课 | 允许；低年级选高年级课拒绝 40007 |
| 并发抢最后一个名额 | 只有一个请求影响行数为 1，其余返回 40002 |
| 同一 Idempotency-Key 重复提交 | 第二次直接返回首次结果，不扣减 |

## 六、时间与节次

- 一周按 5 个工作日 × 12 节建模，节次索引 `(dayOfWeek - 1) * 12 + (section - 1)`，共 60 位。
- 上午 1-4 节、下午 5-8 节、晚上 9-12 节。
- 单双周课程用 `week_type`（ALL / ODD / EVEN）标记，课表按周次过滤显示。
