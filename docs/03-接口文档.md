# 接口文档

完整契约见 `.codebuddy/skills/course-selection-dev/references/api-spec.md`，本文给出调试用速查表与 curl 示例。

## 1. 约定

- Base：`http://localhost:8080/api`
- 鉴权：`Authorization: Bearer <token>`
- 统一响应：`{ code, message, data }`，`code = 0` 表示成功
- 业务异常 HTTP 状态仍为 200，错误码见下表
- 在线文档：启动后访问 `http://localhost:8080/swagger-ui/index.html`（springdoc-openapi），原始契约 `http://localhost:8080/v3/api-docs`

## 3. 调试示例

```bash
# 登录（学生）
curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"20240001\",\"password\":\"123456\"}"

# 当前学期与轮次
curl -s http://localhost:8080/api/semesters/current -H "Authorization: Bearer $TOKEN"

# 教学班列表
curl -s "http://localhost:8080/api/teaching-classes?semesterId=1&onlyAvailable=true&page=1&size=20" \
  -H "Authorization: Bearer $TOKEN"

# 选课（必须带幂等键）
curl -s -X POST http://localhost:8080/api/enrollments \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 3f2a9c1e-6b7d-4a2e-9c1f-8d4b2a6e7f01" \
  -d '{"teachingClassId":101}'
```

## 4. 错误码

| code | 含义 | HTTP |
|---|---|---|
| 0 | 成功 | 200 |
| 40001 | 不在选课窗口 | 200 |
| 40002 | 容量已满 | 200 |
| 40003 | 时间冲突 | 200 |
| 40004 | 先修未通过 | 200 |
| 40005 | 学分超限 | 200 |
| 40006 | 已选过 / 重复提交 | 200 |
| 40007 | 跨年级越级 | 200 |
| 40008 | 该课程不可退 | 200 |
| 40009 | 请求过频 | 200 |
| 40010 | 名单已锁定 | 200 |
| 40100 | 未登录 / token 失效 | 401 |
| 40300 | 无权限 | 403 |
| 50000 | 服务器内部错误 | 500 |

## 5. 前端调用约定

- `src/api/request.ts` 统一注入 token、解析 `code`、`code !== 0` 直接 `MessagePlugin.error(message)` 并 reject
- 选课请求在拦截器外单独生成 `Idempotency-Key`
- 401 时清除本地登录态并跳转 `/login`
