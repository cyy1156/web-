数据库：MySQL 8.4，`utf8mb4`，引擎 InnoDB。建表脚本：`db/schema.sql`。

## 2. 表结构

### 2.1 基础数据

| 表 | 字段 | 说明 |
|---|---|---|
| `college` | id, name, code | 8 个学院 |
| `major` | id, college_id, name, grade | 20 个专业 |
| `student` | id, student_no(U), name, gender, grade, major_id, class_name | 2000 人 |
| `teacher` | id, teacher_no(U), name, title, college_id | 120 人，无登录 |
| `course` | id, code(U), name, credits, hours, course_type, assessment, college_id, description | 200 门 |
| `course_prerequisite` | id, course_id, pre_course_id, min_score | 先修关系 |
| `training_plan` | id, major_id, grade, term_no, course_id, required_type | 培养计划 |
| `sys_user` | id, username(U), password, role, ref_id, status | 登录账号 |

`course_type` 枚举：`REQUIRED` 必修 / `LIMITED` 限选 / `ELECTIVE` 任选。
`required_type` 枚举：`COMPULSORY` / `ELECTIVE`。

### 2.2 学期与轮次

```sql
CREATE TABLE semester (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  year INT NOT NULL,
  term TINYINT NOT NULL,
  name VARCHAR(64) NOT NULL,
  start_date DATE NOT NULL,
  total_weeks INT NOT NULL DEFAULT 18,
  current_week INT NOT NULL DEFAULT 1,
  locked TINYINT NOT NULL DEFAULT 0,
  UNIQUE KEY uk_year_term (year, term)
);

CREATE TABLE selection_round (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  semester_id BIGINT NOT NULL,
  round_no TINYINT NOT NULL COMMENT '1海选 2补选 3退改选',
  name VARCHAR(32) NOT NULL,
  start_time DATETIME NOT NULL,
  end_time DATETIME NOT NULL,
  allow_drop TINYINT NOT NULL DEFAULT 1,
  status VARCHAR(16) NOT NULL DEFAULT 'PENDING' COMMENT 'PENDING/OPEN/CLOSED',
  UNIQUE KEY uk_sem_round (semester_id, round_no)
);
```

### 2.3 教学班（超卖防线）

```sql
CREATE TABLE teaching_class (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  semester_id BIGINT NOT NULL,
  course_id BIGINT NOT NULL,
  class_no VARCHAR(16) NOT NULL,
  teacher_id BIGINT NOT NULL,
  capacity INT NOT NULL,
  selected_count INT NOT NULL DEFAULT 0,
  time_bitmap BIGINT NOT NULL DEFAULT 0 COMMENT '周1-5 × 12节 = 60bit',
  campus VARCHAR(32) DEFAULT '军工路',
  classroom VARCHAR(64),
  status VARCHAR(16) NOT NULL DEFAULT 'OPEN',
  UNIQUE KEY uk_sem_course_class (semester_id, course_id, class_no),
  KEY idx_sem_status (semester_id, status),
  CONSTRAINT ck_capacity CHECK (selected_count BETWEEN 0 AND capacity)
);

CREATE TABLE class_time (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  teaching_class_id BIGINT NOT NULL,
  day_of_week TINYINT NOT NULL COMMENT '1-5 周一到周五',
  start_section TINYINT NOT NULL COMMENT '1-12 节',
  end_section TINYINT NOT NULL,
  week_type VARCHAR(8) NOT NULL DEFAULT 'ALL' COMMENT 'ALL/ODD/EVEN',
  KEY idx_class (teaching_class_id)
);
```

### 2.4 选课记录（幂等与可重选）

```sql
CREATE TABLE enrollment (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  student_id BIGINT NOT NULL,
  semester_id BIGINT NOT NULL,
  teaching_class_id BIGINT NOT NULL,
  course_id BIGINT NOT NULL,
  round_id BIGINT NOT NULL,
  credits DECIMAL(3,1) NOT NULL,
  status VARCHAR(16) NOT NULL DEFAULT 'SELECTED',
  status_flag TINYINT GENERATED ALWAYS AS (IF(status = 'SELECTED', 1, NULL)) STORED,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  dropped_at DATETIME NULL,
  UNIQUE KEY uk_stu_class (student_id, teaching_class_id, semester_id, status_flag),
  UNIQUE KEY uk_stu_course (student_id, course_id, semester_id, status_flag),
  KEY idx_stu_sem (student_id, semester_id, status),
  KEY idx_class_status (teaching_class_id, status)
);

CREATE TABLE enrollment_log (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  student_id BIGINT NOT NULL,
  teaching_class_id BIGINT NOT NULL,
  action VARCHAR(16) NOT NULL COMMENT 'ENROLL/DROP',
  result_code INT NOT NULL,
  message VARCHAR(255),
  idempotency_key VARCHAR(64) NULL,
  cost_ms INT,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_idem (idempotency_key),
  KEY idx_stu_time (student_id, created_at)
);
```

## 3. 两个关键设计

### 3.1 `status_flag` 生成列

```sql
status_flag TINYINT GENERATED ALWAYS AS (IF(status = 'SELECTED', 1, NULL)) STORED
```

MySQL 唯一索引允许多个 `NULL`，因此：

- 选课时 `(student, course, semester, 1)` 唯一 → 防同课程多班
- 退课后 `status='DROPPED'` → `status_flag` 变 `NULL` → 可再次选课

一张表同时解决"防重复"和"可重选"，不需要额外的有效标记字段或软删除表。

### 3.2 `time_bitmap` 位图

- 位索引：`(dayOfWeek - 1) * 12 + (section - 1)`，共 60 位，落在 1 个 BIGINT
- 合并：`mask |= ((1L << count) - 1) << start`
- 冲突判断：`(studentBusy & classMask) != 0`，O(1)

## 4. 容量一致性

`selected_count` 与实际记录数必须一致，由三层保证：

1. 业务层：`UPDATE ... WHERE selected_count < capacity` 原子扣减
2. 事务层：扣减与 `INSERT enrollment` 同事务，失败一起回滚
3. 约束层：`CHECK (selected_count BETWEEN 0 AND capacity)` 兜底

对账 SQL：

```sql
SELECT tc.id, tc.selected_count,
       (SELECT COUNT(*) FROM enrollment e
        WHERE e.teaching_class_id = tc.id AND e.status = 'SELECTED') AS actual
FROM teaching_class tc
HAVING tc.selected_count <> actual;
```
